MatataStudio (formerly Matatalab) is a STEM education technology company founded in 2017. Their products are used in 1,000+ educational institutions worldwide. The brand evolved from Matatalab to MatataStudio as it expanded its product range.

### Product Overview

The **MatataStudio Coding Set Pro Classroom Set** is a complete, screen-free coding and robotics solution designed for early primary classrooms (ages 4–9). The classroom set contains 6 Coding Set Pro kits plus full teacher resource materials, enabling a class of up to 24 students (4 per group) to simultaneously engage in hands-on coding activities.

The Coding Set Pro is the **advanced version** of MatataStudio's base Coding Set — it adds music (Musician add-on) and art/drawing (Artist add-on) capabilities with additional angle blocks, music note blocks, washable markers, and warm-up activity cards. These creative extensions allow children to program their MatataBot to draw shapes and compose melodies, extending coding into cross-curricular art and music projects.

The system is entirely screen-free and word-free: children arrange physical coding blocks with graphic symbols on a control board, then the Command Tower reads the sequence via image recognition camera and transmits the program to the MatataBot via Bluetooth. The robot executes the commands immediately, giving instant visual feedback.

## Learning Outcomes (Expanded)

### Why Hands-On, Screen-Free Learning Works

Research strongly supports the screen-free, physical approach used by MatataStudio for early learners:

- A systematic review of 22 peer-reviewed studies (PMC, 2023) found that educational robotics is "a promising learning approach for computational thinking development" for pre-K through 6th grade — even the youngest students can develop sequencing and debugging skills.
- Programming on-screen is challenging for younger learners due to limited reading, writing, typing, and fine-motor development. Physical robots like MatataBot remove these barriers and make early coding accessible from age 4.
- The top 5 computational thinking skills successfully developed through educational robotics: **sequencing** (13 studies), **conditionals** (8 studies), **loops** (6 studies), **debugging** (6 studies), and **algorithmic thinking** (5 studies) — all of which are core concepts in the Coding Set Pro curriculum.
- **Collaborative learning** (used in 15 of 22 studies) is a key success factor. The 4-student group format of the classroom set directly aligns with this evidence base.
- Robots as "manipulatives with immediate feedback" reduce cognitive load and support deeper understanding than passive instruction.

**Source:** PMC systematic review — https://pmc.ncbi.nlm.nih.gov/articles/PMC10078047/

A 7-year study of 862 students aged 7–10 found:
- Coding skills improved from **3% to 92% proficiency** after a robotics programme
- Robotics design knowledge improved from **26% to 93% proficiency**
- **32% increase** in computing career interest
- Students who participated for two years showed significantly greater gains

**Source:** PMC study on early robotics education — https://pmc.ncbi.nlm.nih.gov/articles/PMC10871080/

### STEM Skills

**Computational Thinking & Programming Concepts:**
- Sequencing — arranging blocks in the correct order to produce an outcome
- Loop structures — using Loop Begin/End blocks with Number blocks to repeat commands
- Conditionals — programming if/then logic in the robot's behaviour
- Functions — defining reusable code blocks and calling them multiple times
- Debugging — identifying why a program didn't work and correcting it
- Algorithmic thinking — breaking a problem into steps the robot can follow
- Abstraction — representing complex movements or tasks as simple symbolic commands

**Mathematics:**
- Spatial reasoning — planning robot routes on a grid map
- Angles and geometry — using angle blocks (30°–150°) to program shapes and drawings
- Counting and number sense — working with Number blocks for loop parameters
- Measurement and estimation — predicting distances and turns

**Music & the Arts:**
- Music theory fundamentals — sequencing Alto and Treble clef note blocks to compose melodies
- Geometric shape drawing — programming the robot to draw squares, triangles, and other shapes using angle blocks and washable markers
- Creative design — combining coding, music, and art in cross-curricular projects

**Science & Engineering:**
- Cause and effect — observing what happens when code changes
- Testing and iteration — running programs, observing outcomes, adjusting
- Basic robotics concepts — how a robot receives and processes instructions

**Curriculum formats included:**

- **Extracurricular Curriculum** (12 lessons): Focus on cross-curricular integration; suitable for after-school clubs and STEM programmes
- **Artist Add-On Curriculum**: Programming angle-based robot drawing using the washable marker
- **Musician Add-On Curriculum**: Composing melodies by sequencing music note blocks

**Challenge Booklets (3 per kit):**
Each kit includes 3 colour-coded challenge booklets that guide learners from beginner-friendly tasks to advanced challenges:
- **Booklet 1 (Beginner):** Basic robot navigation — moving to a destination, obstacle avoidance
- **Booklet 2 (Intermediate):** Loop-based challenges, shape programming, music warm-ups
- **Booklet 3 (Advanced):** Functions, complex routes, combined creative coding tasks

**Activities overview (types across curriculum):**
- **Navigation challenges:** Program the MatataBot to travel a specific route on the double-sided map using directional and number blocks
- **Loop challenges:** Reduce a long sequence to a compact loop; draw geometric shapes using repeated angle commands
- **Function challenges:** Identify repetition in code, create a function block, and reuse it across a program
- **Drawing challenges:** Attach the washable marker and program the robot to draw squares, triangles, circles, and patterns
- **Music challenges:** Arrange music note blocks to compose a melody; use Loop blocks to repeat musical phrases
- **Storytelling challenges:** Use the map and robot to enact a narrative — navigate through obstacles and scenarios
- **Warm-up activities:** Artist and Musician warm-up cards introduce each creative capability before independent challenges

**Total activities:** Across both 12-lesson curricula, 3 challenge booklets per kit, plus Artist and Musician warm-up cards: approximately **60–70+ structured activities and challenges** spanning the full curriculum. (Exact count varies across product versions; the Shopify description notes "100+ stories and challenges" across the platform.)

**Difficulty progression:** Activities are ordered by logical difficulty — introduction → understanding → application — within each unit. The three challenge booklets follow the same progression.

### Life Skills & Character Development

**Critical Thinking & Problem-Solving:**
- Every challenge requires children to plan before acting — thinking ahead about which blocks to use and in what order
- When the robot doesn't do what was expected, children must diagnose and fix the problem (debugging) — a powerful real-world problem-solving skill
- Children learn to break complex goals into smaller, manageable steps

**Resilience & Growth Mindset:**
- The instant feedback loop (place blocks → run program → observe result) makes mistakes visible and immediately actionable — children experience failure as a natural, fixable part of the process
- Research shows robotics "reminds students that mistakes are not failures — they are opportunities to grow"
- Children who struggle with reading or writing often excel with robotics, building confidence that spills over into other subjects

**Collaboration & Communication:**
- 4-student group format requires children to negotiate, take turns, share ideas, and explain their thinking
- Peer coaching has been shown to benefit both the student giving and receiving guidance
- Working together toward a shared goal builds communication skills and social awareness

**Creativity & Innovation:**
- The Artist and Musician add-ons invite open-ended creative expression — there is no single "right" drawing or melody
- LEGO® compatibility enables children to customise and build structures for the MatataBot to navigate
- Children naturally explore possibilities beyond prescribed challenges

**Emotional Regulation:**
- The structured challenge progression (easy → hard) helps children experience achievable wins before tackling more difficult problems
- Collaborative format distributes difficulty — no child faces frustration alone
