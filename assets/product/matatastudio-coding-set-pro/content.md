### Product Overview

The MatataStudio Coding Set Pro is a screen-free, app-free, and internet-free coding robot set designed for children ages 4-9. It eliminates potential harm to kids' eyes while making coding tangible and playful through physical coding blocks marked with directional symbols.

**Key Differentiators:**
- **Pro Set vs. Standard Coding Set:** The Pro Set includes music blocks and angle blocks, while the standard Coding Set does not. The Coding Set is a basic version suitable for homeschooling children without a coding foundation, while the Pro Set is a more professional version suitable for advanced code learning and classroom use.

## Learning Outcomes (Expanded)

### Why Hands-On, Screen-Free Coding Works

**Research-Backed Benefits of Tangible Coding:**

Educational theorists have long recognized that young children think and learn best when moving, playing, building, and engaging with concrete objects. Studies demonstrate that young children benefit from connecting programming concepts to concrete, physical objects, reinforcing learning in an age-appropriate way.

**Key Research Findings:**

1. **Tangible vs. Screen-Based Learning:**
   Research shows that children using tangible robotics (such as physical coding robots) performed **27% better on computational thinking** than children using screen-based tools. After working with tangible robots, 2/3 of girls expressed an interest in engineering careers — a rate equal to boys.

2. **Developmental Appropriateness:**
   Tangible coding using physical screen-free robots and blocks addresses the learning styles and cognitive abilities of early childhood. Elementary-aged students learn better with concrete, physical manipulatives than abstract on-screen representations. Studies indicate that not only is it possible to infuse programming in the early schooling years, but that developmentally appropriate technologies and strategies promote creativity and cognitive growth.

3. **Screen Time Concerns:**
   With classrooms already filled with digital learning and studies showing negative effects of screen-time, unplugged options are being considered. Research indicates "vulnerability in physical, social, emotional, and cognitive developmental health domains" with excessive screen exposure. Similar to play-based learning, which has demonstrated holistic development, unplugged learning with manipulatives has been found effective and motivating.

4. **Executive Function Development:**
   Studies demonstrate the positive effects of educational robotics on working memory and inhibition skills of 5-to-6-year-old children. Research has shown that teaching computational thinking through both unplugged and plugged activities has a significant effect on executive functions associated with working memory, planning, and inhibition.

5. **Immediate, Tangible Feedback:**
   Unlike traditional coding exercises with delayed or virtual feedback, robotics provides immediate, tangible results. When a robot physically moves in response to code, abstract concepts like sequencing and conditionals become vivid and memorable.

**Statistics:**
- Children using tangible coding robots showed **27% improvement** in computational thinking vs. screen-based tools
- Educational robotics significantly improves working memory, planning, and inhibition skills
- 2/3 of girls expressed interest in engineering careers after hands-on robotics (equal to boys)
