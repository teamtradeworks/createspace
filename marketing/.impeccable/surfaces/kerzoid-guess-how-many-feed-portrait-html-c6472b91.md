# Meta ads: Makerzoid "Guess how many" (4:5 feed)

Scope: two static Meta feed posts, 1080x1350. A comment-prompt guess post and the Friday reveal post. Mode: Persuade (engagement first, product second).
Audience: SA parents. Action: comment a guess; on reveal, see the answer and tap through to the product.
Proof: the Shopify box shot; real facts only (200+ robot models, 600+ pieces). No prize, so no competition terms.
Constraints: brand world is marketing/DESIGN.md, except the brief pins a solid Spark Yellow ground and an Outfit ExtraBold 104px headline. Brief: marketing/campaigns/2026-10-makerzoid-guess-how-many/brief.md.

## Direction contract
THESIS: A playground-simple guessing game: one question, one box, one big "?". Refuses the product-ad layout (price, CTA button, age pill) so it reads as a game, not an ad.
