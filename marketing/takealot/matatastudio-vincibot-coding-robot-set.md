## Description

The **MatataStudio VinciBot** is a coding robot that takes kids from their first drag-and-drop blocks to writing real Python code. It comes fully assembled with three preset modes (line following, drawing and remote control), so the fun starts the moment it's out of the box.

Using the free MatataCode app, kids work through 75 guided lessons, coding VinciBot to dance, draw pictures, light up and steer around obstacles. As their skills grow, they can try AI and IoT projects too. Each mistake shows up on the robot, so they learn to spot it, fix it and try again.

**Key Features**
- Start with drag-and-drop blocks, then move on to Python in the same app
- 75 guided online lessons, plus an 18-challenge booklet in the box
- Play straight away with line following, drawing and remote control modes
- 8 built-in sensors detect light, sound, colour, distance and lines
- LED face, colourful lights and a speaker with 21 instrument sounds
- Learns to recognise hand gestures and handwriting, no internet needed
- Works with LEGO bricks and Technic motors for custom builds
- Rechargeable battery with 4+ hours of play per charge
- Free app for Windows, Mac, iPad and Android tablets
- Builds logic, problem solving and computational thinking
- Recommended age range: 8+ years

**Batteries required:** Built-in rechargeable lithium battery (included). Charges via USB.

**Warning:** Contains a lithium battery. Adult supervision recommended when charging. Not suitable for children under 3 years.
