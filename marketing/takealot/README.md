# Takealot Listings

Copy and listing details for CREATESPACE products sold on Takealot. One file per product, named by the Shopify handle.

Each file holds:
- **Subtitle**: the line under the title, with search keywords, in the form "what it is - key benefit (age X+)"
- **Description**: short intro, Key Features list, batteries, warning and "What's in the box", matching the layout of our live listings (e.g. Makerzoid Robot Master Premium, National Geographic Glow-in-the-Dark Human Body)
- **Category**: Takealot category path, chosen by checking where similar products are listed
- **Size + weight**: boxed size and weight, with the Takealot fulfilment band (Standard up to 35,000 cm³; Light up to 7 kg)
- **Other details**: age, material, batteries, brand, model number, barcode
- **Notes**: claims left out and facts to check against stock before submitting

Facts come from the research in `assets/product/{slug}/content.md`. Box sizes and weights come from retailer listings, so measure a unit from stock before submitting.
