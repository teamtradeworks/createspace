## Description

The **MatataStudio Nous AI Set** is a build-it-yourself robot that shows teens how artificial intelligence really works. They snap together the hub, camera and motor modules in about 20 minutes, then code Nous in their web browser with blocks or Python.

Teens train Nous to recognise faces, objects and spoken commands, have conversations with it through MatataChat, and run self-driving and line-following challenges on the included maps. Trained AI models run on the robot itself, so learners see each step from collecting data to a working smart machine.

**Key Features**
- Train AI models for images, sounds and distance, then run them on the robot
- Camera recognises faces and objects, and tracks faces and colours
- Chat with Nous using MatataChat, powered by ChatGPT-4o (needs internet)
- Code with Scratch-style blocks or Python
- Browser-based MatataCode platform, with no software to install
- Step-by-step online lessons, from first projects to advanced AI
- Line-following and autopilot maps, plus recognition cards
- Camera module with fill lights and a distance sensor
- Servo module that works in motor or servo mode
- Metal build that works with building blocks for custom robots
- Built-in rechargeable battery, charges via USB-C
- Needs a computer or tablet with internet for coding and lessons
- Recommended age range: 12+ years

**Batteries required:** Built-in rechargeable battery (included). Charges via USB-C.

**Warning:** Choking hazard. Small parts. Not for children under 3 years. Contains a rechargeable battery. Adult supervision recommended when charging.
